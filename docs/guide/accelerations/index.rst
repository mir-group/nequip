Accelerations
=============

Performance optimization techniques for faster training and inference.

The combined effect of these accelerations on training and inference speed, memory demand, and multi-GPU scalability is benchmarked in the `NequIP foundation potentials paper <https://doi.org/10.48550/arXiv.2607.28461>`_.
