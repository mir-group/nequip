User Guide
==========

This guide covers using NequIP, from initial setup to advanced optimization techniques.

**Getting Started** provides framework-level information for new users, including installation, basic workflow, file types, and the pretrained :doc:`foundation potentials <getting-started/foundation_potentials>`.

**Configuration** covers setting up training runs, including config files, data preparation, and model configuration.

**Training Techniques** explores advanced training methods like :doc:`fine-tuning <training-techniques/fine_tuning>` (e.g. of the :doc:`foundation potentials <getting-started/foundation_potentials>`) and multitask learning.

**Accelerations** details performance optimization techniques for faster training and inference.

**Reference** contains conventions, troubleshooting guides, and frequently asked questions.
